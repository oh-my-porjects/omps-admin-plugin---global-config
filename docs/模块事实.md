# 全局配置 模块事实

## 职责

全局配置公共模块，负责配置项列表、详情、更新和恢复默认值，并提供后台权限校验。

## 数据表

- `global_configs_items`

## API

- `GET /api/global_config/hello`：模块探活
- `GET /api/global_config/config/list`：查询配置列表
- `GET /api/global_config/config/detail`：查询配置详情
- `POST /api/global_config/config/update`：更新配置值
- `POST /api/global_config/config/reset-default`：恢复默认配置
- `POST /api/global_config/admin/ping`：后台连通性检查

## 项目后台 V4

- `/system/configs` 是本模块唯一可导航页面，使用 `standard-list` 承载配置列表。
- 查看和修改均从配置列表通过 `open-dialog` 打开；查看使用 `standard-detail`，修改使用带 `submit_action` 的 `standard-form`。
- 恢复默认值保留为列表行上的受控确认动作；本模块不再提供独立配置详情页、修改页或对应菜单。

## 实时事件

用户前端事件：

- 当前模块没有自有用户前端推送事件。

后台提醒事件：

- 当前模块没有自有后台实时提醒事件。

## 测试资产

- `tests/data.yaml` 声明本模块测试涉及的数据表、种子、清理和快照范围。
- 每个 `api-docs/endpoints/*.json` 里的 `endpoint_key` 都应有对应 `tests/*.test.json`。
- 新增、删除或修改接口时，必须同时更新 `api-docs/`、测试文件和必要的数据种子。
